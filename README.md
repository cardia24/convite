# Convite para jantar

Página estática e responsiva, pronta para GitHub Pages.

Para visualizar localmente, abra `index.html` ou execute `python3 -m http.server 8000` nesta pasta.

Para publicar, abra **Settings → Pages** no GitHub, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`.

Os textos ficam em `index.html` e as interações em `script.js`.
